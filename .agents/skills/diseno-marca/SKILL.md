# Skill: Diseño de marca — Banco de Alimentos Comunitario

## Propósito
Diseñar interfaces que transmitan confianza, dignidad, colaboración y claridad. La marca debe sentirse comunitaria y humana, no corporativa ni infantil.

## Personalidad
- Cercana y respetuosa.
- Práctica y optimista.
- Transparente y confiable.
- Inclusiva para personas mayores y usuarios con baja alfabetización digital.

## Dirección visual
- Paleta sugerida:
  - Verde bosque `#245C45`: confianza, acciones principales.
  - Verde suave `#E8F2EC`: fondos informativos.
  - Amarillo cálido `#F4C95D`: avisos y atención.
  - Terracota `#B94B3A`: errores o vencidos; nunca como único indicador.
  - Marfil `#FAF8F2`: fondo general.
  - Gris carbón `#26332D`: texto principal.
- Tipografía: sistema sans-serif legible; mínimo recomendado 16 px para texto normal.
- Formas: tarjetas simples, bordes suaves y espacios generosos.
- Iconografía: familiar y acompañada de texto; no depender de iconos aislados.
- Fotografía: si se usa en el futuro, mostrar alimentos y colaboración comunitaria con dignidad; evitar imágenes estereotipadas de pobreza.

## Componentes
- Botón principal: verde bosque, texto blanco, alto mínimo 48 px.
- Botón secundario: fondo claro, borde visible.
- Estados: usar etiqueta textual más color (“Pendiente”, “Ya recibió ayuda”, “Vencido”).
- Formularios: etiquetas persistentes, ayudas breves y errores junto al campo.
- Confirmaciones: explicar qué producto y cantidad se registrarán antes de guardar.

## Accesibilidad
- Contraste de texto suficiente (objetivo WCAG AA).
- Foco de teclado visible.
- Controles grandes y separados.
- No usar solo color para comunicar estados.
- Lenguaje directo: “Registrar entrega”, no “Ejecutar transacción”.
- Evitar animaciones decorativas y pantallas saturadas.

## No hacer
- No usar estética de supermercado, fintech o software empresarial.
- No usar tipografía pequeña, texto gris claro ni botones compactos.
- No usar rojo/verde como único medio para distinguir estados.
- No introducir ilustraciones que distraigan de la tarea principal.

## Instrucción al agente
Antes de crear o modificar una pantalla, consulta esta skill. Mantén consistencia de paleta, jerarquía, componentes, tono y accesibilidad. Si una decisión visual compite con la facilidad de uso, prioriza facilidad de uso.
